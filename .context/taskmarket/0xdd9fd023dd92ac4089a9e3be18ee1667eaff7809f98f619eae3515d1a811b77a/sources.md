# Sources

CERN is the source named in the brief.

Facts used from the locked brief:

- At CERN's Large Hadron Collider, ATLAS and CMS are two separate collaborations.
- Each collaboration includes thousands of people.
- They study the same particle collisions with different detectors.
- They analyze blind and independently, hiding the signal region until methods are fixed.
- A result counts as real only when both machines see it.
- This is how the Higgs boson was confirmed in 2012.
