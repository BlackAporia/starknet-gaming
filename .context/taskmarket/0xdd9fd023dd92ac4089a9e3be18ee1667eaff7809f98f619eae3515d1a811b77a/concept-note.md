# Concept Note

Title: Two Blind Machines

This is a self-contained interactive page that turns CERN's independent blind-confirmation process into a two-minute action. The reader must fix the ATLAS method and the CMS method before the hidden signal region can be opened. The final state appears only when both teams are locked and both see the same signal.

The visual language is a printed science-table feel: warm paper, restrained detector colors, and a simple hidden-data plot. The interaction is deliberately small because the core idea is procedural, not decorative: discovery depends on independent agreement after blinding, not on one impressive-looking result.

Surprise element: the chart visibly suppresses the signal region until the reader has locked both teams, so the interface itself enforces the scientific rule.
